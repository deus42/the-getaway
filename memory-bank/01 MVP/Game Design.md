## Narrative and UI guidance contract
- [[03 Lore/Plot Bible]] is the source of truth for story premise, tone, dialogue voice, factions, and motifs.
- [[35 Narrative Alignment]] is the MVP authoring contract for applying the Plot Bible to quest text, dialogue, George guidance, objective labels, logs, and other player-facing narrative UI copy.
- Keep durable gameplay/narrative rules in this memory bank. Chat-only instructions are not enough; when dialogue, quest structure, or player-facing text rules change, update the relevant MVP design note and cite the Plot Bible section that anchors the change.
- Keep planning and progress separate: implementation plans describe intended scope, while `progress/*.md` task notes and the roadmap progress log record status and completion evidence.
